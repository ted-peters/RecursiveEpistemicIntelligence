# Recursive Epistemic Intelligence (REI) — Interactive Public Research Demo

This free static Space runs **the original REI-1.0 typed epistemic graph Python modules in your browser** using [Pyodide](https://pyodide.org/). It is a real, deterministic software demonstration: fictional evidence is added, assessed, and revoked by REI's actual graph code rather than merely displaying a prerecorded outcome table.

**No trained language model, external evidence verification, live model inference, or paid API calls are involved.** All example sources and review approvals are synthetic. Four-state evidence labels track the *recorded evidence*, not objective truth. Browser-based Python is loaded from a pinned public Pyodide CDN; an internet connection to the CDN is required on first load.

Complete REI-1.0 research source: [GitHub — RecursiveEpistemicIntelligence](https://github.com/ted-peters/RecursiveEpistemicIntelligence).

This is a research demonstration, **not proof that REI is more accurate than conventional AI**.
