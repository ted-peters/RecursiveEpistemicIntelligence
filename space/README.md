# Recursive Epistemic Intelligence (REI)

This Space runs the **original REI-1.0 typed epistemic graph code** to demonstrate four-state support tracking, duplicate-origin handling, and revocable example evidence.

**This is NOT a trained language model or independent AI-vs-AI benchmark.** Examples are fictional and approvals are simulated. No API calls, paid inference, private test answers, or reviewer credentials are used.

The complete repository includes the bounded recursive inquiry engine, formal blueprint, review service, and research tools; only the minimum graph components needed for the public demo are copied here.

For research status, see the GitHub repository README when published.
