# REI Challenge 5 — Results available so far

**Status:** research package prepared and offline validation executed. **Not yet a live-model head-to-head.**

## What has actually been tested

- Frozen public/private dataset schemas, disjoint calibration and evaluation case identifiers, and deterministic problem-key generation.
- Logic keys by exhaustive Boolean truth-table enumeration; evidence transitions and dependency rules by deterministic code.
- The test program rejects synthetic reports as evidence of live AI superiority.
- Calls to external models are disabled unless both an explicit consent flag and a key exist.
- Original REI-1.0 source included without alteration; see readiness report for tests executed in this session.

## What has not happened

- No independent external language-model call.
- No observation of baseline or REI answers to new unseen cases.
- No performance difference, confidence interval, or scientific winner to report.

## Predeclared outcome

Primary: REI minus self-critique overall success across 60 evaluation questions × 3 repetitions. Secondary: direct baseline and fixed-depth. Also measure actual model usage, failures, abstention and confidence calibration.

The scientific next action is to run the locked study through independently provisioned model access. The user is not expected to install or operate the scripts.
