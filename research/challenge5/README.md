# Challenge 5 public research materials

This directory contains **public problem statements and research code**, not the private reference answers. No independent model comparison has yet been executed.

- `calibration_cases.json`: 20 synthetic practice tasks.
- `evaluation_cases.json`: 60 synthetic evaluation tasks. These questions have previously been distributed to the project owner; **do not treat them as a newly secret blind benchmark**.
- `generate.py` can reproduce the synthetic tasks, including reference answers, so these are not cryptographically secret or suitable for a definitive independent blind study.
- The original locally frozen exploratory study and its old key files are retained **only in the separate private archive**.

If conducting genuine blinded research, commission a genuinely new test set kept by an independent evaluator. For local tests, create temporary keys with the generator's documented functions and keep them private.
