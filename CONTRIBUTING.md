# Contributing to REI

Contributions are welcome to improve correctness, documentation, and reproducible research. Please open an issue describing the proposed change, then supply deterministic tests where possible. Do not describe scripted examples as independent empirical evidence. Never commit API keys, reviewer private keys, private answer files, or identifying source artifacts. Security reports should avoid public disclosure of working exploits against deployments you do not control.

The existing system deliberately separates claims from verified evidence. Preserve that separation in changes.
